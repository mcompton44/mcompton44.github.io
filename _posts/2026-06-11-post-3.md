## Day 3: TESS Lightcurves

Today I was able to extract lighturves from full frame images for the first four stars from the paper database. I have included two of these at the bottom of my post. The program runs well, but you have to enter 
the ID number, search for its sectors, then enter in the sectors to get a lightcurve for a star, which would obviously take a long time to repeat for the entire sample of around 450 stars that we are working with.
I wanted the process to be more efficient, so I started coding a way for the lightkurve code from the TESS tutorials to mass produce the lightcurves instead of having to manually impur the ID number and sector every
time. First I had to refromat the TESS ID column data to include 'TIC' at the front of the number, because that is the format the lightkurve search function works with. So far I have made a for loop that can produce
the search result for every star in the sample. Next, I want to be able to grab the sectors corresponding to each ID number, then make a lightcurve for each sector. I'm glad I was able to produce the lightcurves today
and I think working on some automation for the process will be useful in the future. Sara mentioned that the TGLC server was down, so that is unforunate we weren't really able to get anything from that, but I think 
the tools we do have will be sufficient.
