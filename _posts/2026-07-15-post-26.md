## Day 26: Quality Flags to Clean Lightcurves and Creating Nearby Source Catalog

Today I was able to implement the TESS quality flags to greatly improve the quality of my lightcurves, and therefore produce much better periodograms (one of which
I will attach below). I went with the 'hard' version of the quality flags because I was unconcerned about accidentally masking out flares, as those overall do not
impact the double periods. I also was able to find the astropy code that calculates angular separation, and started using that to find angular separation values
between my pricipal sources and potential nearby interfering sources, as well as record their Gmag and GAIA EDR3 source IDs. This data will help us decide if the 
nearby sources are actually interfering in the lightcurves in a way that makes it seems like the main source has a double period, instead of that actually being an
intrinsic characteristic.
